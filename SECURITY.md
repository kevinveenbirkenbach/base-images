# Security Policy

## Supported Versions

Only the current images receive security fixes. Every distribution is rebuilt
daily from its upstream base, and `latest` and each major tag always carry the
most recent build, so a fixed upstream package reaches them without a release.

## Reporting a Vulnerability

Please do not report security issues in a public issue or pull request.

Report them privately through either channel:

- GitHub: [report a vulnerability](https://github.com/kevinveenbirkenbach/base-images/security/advisories/new)
- Email: Kevin Veen-Birkenbach, [kevin@veen.world](mailto:kevin@veen.world), [veen.world](https://veen.world)

Include the affected image and tag, the steps to reproduce, and the impact you
expect.
